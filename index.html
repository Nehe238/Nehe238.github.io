Type 1 — Numerical Questions

3 questions × 3 = 9 points

Q1.1. Transmission and Propagation Delay

Two hosts are connected by a link with a transmission rate of 2 Mbps. The distance between them is 1,000 km, and the propagation speed is 2 × 10⁸ m/s. A packet contains 1,000 bytes. Ignore processing and queuing delays.

  1. Calculate the transmission delay.
  2. Calculate the propagation delay.
  3. Calculate the time from the start of transmission until the entire packet arrives at the destination.
정답 및 한국어 해설

a. 4 ms — L = 1,000 × 8 = 8,000 bits. dtrans = L/R = 8,000/(2 × 10⁶) = 0.004 s.

b. 5 ms — m = 10⁶ m. dprop = m/s = 10⁶/(2 × 10⁸) = 0.005 s.

c. 9 ms — 전송 지연과 전파 지연의 합입니다. 첫 비트의 도착과 마지막 비트의 도착을 구별하세요.

Q1.2. DNS and HTTP Delay

A DNS lookup sequentially visits two DNS servers, incurring RTTs of 10 ms and 20 ms. The RTT between the client and the Web server is 50 ms. The base HTML references four small objects on the same server. Initially, no TCP connection exists. Ignore transmission and processing times.

Calculate the total time from clicking the link until all objects are received:

  1. Non-persistent HTTP with no parallel connections.
  2. Non-persistent HTTP with four parallel connections for the referenced objects.
  3. Persistent HTTP with pipelining: after receiving the base HTML, send all four object requests together over the existing connection.
정답 및 한국어 해설

DNS 조회 시간 D = 10 + 20 = 30 ms. 기본 HTML은 TCP 연결 1 RTT와 요청·응답 1 RTT가 필요합니다.

a. 530 ms — D + 2RTT + 4 × 2RTT = 30 + 100 + 400.

b. 230 ms — D + 2RTT + 2RTT = 30 + 100 + 100. 참조 객체 4개는 동시에 처리합니다.

c. 180 ms — D + 2RTT + RTT = 30 + 100 + 50. 기존 연결로 요청 4개를 한꺼번에 보냅니다.

지속 연결 여부와 파이프라이닝 사용 여부를 구별해야 합니다.

Q5.1. UDP Segment Format

Draw the UDP segment format. Label all header fields and indicate the size of each field in bits. Also state the total UDP header size and what the Length field measures.

그림 연습 공간 · 인쇄 후 직접 그려보세요.
정답 및 한국어 해설
                    32 bits
        +----------------+----------------+
        | Source Port    | Destination    |
        | (16 bits)      | Port (16 bits) |
        +----------------+----------------+
        | Length         | Checksum       |
        | (16 bits)      | (16 bits)      |
        +----------------+----------------+
        |       Application Data          |
        |       (variable length)         |
        +---------------------------------+

각 필드는 16 bits, 헤더 전체는 8 bytes입니다. Length는 UDP 헤더 + 데이터의 전체 길이를 바이트 단위로 나타냅니다.

Q5.2. Receiver FSM for rdt2.2

Draw the receiver FSM for rdt2.2. The initial state is Wait for 0. Show both states, transition conditions, and actions for:

Assume that an ACK1 packet is available initially for duplicate-ACK responses.

그림 연습 공간 · 상태와 화살표 위의 조건 / 동작을 표시하세요.
